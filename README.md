# Contador

Aplicativo Android (Kotlin) desenvolvido no Android Studio.

## Requisitos

- Android Studio (versão recente)
- JDK 11+
- SDK Android (compileSdk 37 / minSdk 24)

## Como rodar

1. Clone o repositório:
   ```bash
   git clone <URL_DO_SEU_REPOSITORIO>
   ```
2. Abra a pasta do projeto no Android Studio.
3. Aguarde o Gradle sincronizar as dependências.
4. Rode o app em um emulador ou dispositivo físico (Run ▶).

## Estrutura do projeto

```
app/
 └── src/
     ├── main/        # código-fonte principal (MainActivity.kt, layouts, recursos)
     ├── test/        # testes unitários
     └── androidTest/ # testes instrumentados
```
